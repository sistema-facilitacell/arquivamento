🤖 Assistente IA — Configuração

Como funciona: A IA é usada para extrair o nome do cliente quando o PDF não é reconhecido automaticamente. Configure pelo menos uma opção gratuita (Groq ou Gemini) para ter extração inteligente sem custo. O sistema tenta na ordem: Groq → Gemini → Ollama → Claude.
⚡
Groq GRÁTIS
Ultrarápido · 14.400 req/dia grátis · console.groq.com
👉 Acesse console.groq.com/keys → crie uma conta grátis → gere uma API key
💎
Google Gemini GRÁTIS
1.500 req/dia grátis · aistudio.google.com
👉 Acesse aistudio.google.com/app/apikey → "Get API key" → grátis sem cartão
🦙
Ollama (Local) 100% GRÁTIS
Roda no seu PC · sem internet · ollama.com
👉 Instale em ollama.com/download → execute ollama run llama3 no terminal
🧠
Claude (Anthropic) PAGO
Mais preciso · pago por uso · console.anthropic.com
👉 Acesse console.anthropic.com → API Keys → Create Key
